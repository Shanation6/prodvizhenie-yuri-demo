# ПроДвижение с Юрием Ряжкиным

Демонстрационный статический сайт для знакомства с тренером, форматами занятий и SUP. HTML/CSS/JS без сборки, сервера, базы данных и форм заявок. Кнопки предлагают звонок на публичный номер Юрия или переход в его Telegram-канал.

## Запуск

Из папки проекта выполните `python -m http.server 4186 --bind 127.0.0.1`, затем откройте http://127.0.0.1:4186/. Все ресурсы размещены локально, пути относительные и работают в подпапке GitHub Pages.

## Проверка и публикация

`node --check assets/app.js` — проверка синтаксиса. `scripts/browser-check.mjs` запускается с путями к установленным Playwright Core и Chromium в переменных `PLAYWRIGHT_MODULE` и `CHROME_PATH`. Проверяет адаптацию, форматы, меню, FAQ, изображения и ошибки браузера. Для опубликованной версии укажите `SITE_URL`.

`python scripts/publish.py` — публикация в отдельный репозиторий GitHub и включение Pages. Используется существующая авторизация Git Credential Manager без записи секретов в файлы. `python scripts/publish.py --status` — статус публикации.
